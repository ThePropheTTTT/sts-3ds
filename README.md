# 杀戮尖塔 · 3DS 版

一个非官方、非营利的同人移植项目，目标是让《Slay the Spire》的核心战斗与地图流程在 Nintendo 3DS 上运行。项目使用 C 与 citro2d 为 3DS 重写表现层，仅供个人学习、研究，以及在自有机型上体验。

本项目自己写的代码以 [MIT 许可证](LICENSE) 发布；《杀戮尖塔》的游戏资源、文本与商标不在该许可范围内，详见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 构建

本仓库不包含生成资源与 `port/source/*_gen.h`。先按 [数据管线](docs/01-data-pipeline.md) 从自购游戏副本生成，再按 [工具链](docs/02-toolchain.md) 配置 devkitPro，最后运行 `bash port/build.sh`。

## 存档

存档位于 `sdmc:/3ds/sts3ds/save.dat`，在地图界面自动写入；读档会校验 magic、版本与 checksum，并用保存的随机种子重建地图。细节见 [存档](docs/03-save.md)。

## 音频

背景音乐从正版 jar 提取为 22050 Hz 单声道 PCM，放到 `sdmc:/3ds/sts3ds/audio/`，运行时优先走 NDSP 流式播放；没有 DSP 固件时回退 CSND。提取命令、固件要求与模拟器备注见 [音频](docs/04-audio.md)。
