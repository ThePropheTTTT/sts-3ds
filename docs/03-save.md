# 存档

## 位置

`sdmc:/3ds/sts3ds/save.dat`。首次运行会自动创建 `sdmc:/3ds/sts3ds/` 目录。

## 何时写盘

只在**地图界面**写盘：

- 新开一局、进入地图时；
- 从战斗奖励、商店、事件、营火、宝箱回到地图时；
- 进入下一幕、新地图生成后；
- 在地图界面按 START 退出时。

战斗中途不写盘，所以关机最多损失当前这一场战斗；磁盘上保留的是进战斗前的地图状态。

## 内容与校验

存档是固定长度的二进制块：

| 字段 | 说明 |
|---|---|
| `magic[4]` | `STS3` |
| `version` | 当前为 1 |
| `Run` | 牌组、遗物、药水、金币增量、卡牌奖励、升级/营火选择等 |
| `MapState` | 节点类型、已走节点、当前行列、商店/事件状态、`map_seed` |
| `hp` / `max_hp` | 当前生命与最大生命 |
| `battle_rng` | 存档时的战斗 RNG 状态 |
| `checksum` | 对前面所有字节的 FNV-1a 校验 |

读档时先校验 magic、版本和 checksum，再检查牌组/遗物/药水数量、幕数、地图坐标等范围。任何一项不合法都当作没有存档，直接开新局，不会带着半截数据进游戏。

## 地图如何还原

地图的边表是 `run.c` 里的静态数组，不进存档。`map_generate()` 在生成前把 `battle_rand()` 的当前状态记进 `MapState.map_seed`；读档时先恢复幕数和这个种子，重新生成一次地图（边、节点类型、商店/事件随机数都会复现），再把存档里的 `MapState` 覆盖回去。这样存档只需要保存几百字节的状态，不必序列化整张图。

## 重新开始

在地图界面按两次 **B**：第一次显示“再按一次 B 放弃本局，重新开始”，2 秒内再按一次即开新局并覆盖存档。想彻底清空，也可以直接删除上面的 `save.dat`。
